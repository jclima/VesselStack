# Repository Instructions

## README synchronization is mandatory

Every repository change must update `README.md` in the same commit or pull
request. This includes code, configuration, dependencies, workflows, scripts,
templates, tests, packaging, security behavior, and other documentation.

Update relevant installation steps, fields, commands, versions, operational
impact, limitations, verification, and rollback guidance. Do not merge a change
when its README update is missing or inaccurate.

Never commit credentials, tokens, vessel positions, MMSIs, call signs, device
identifiers, telemetry databases, logs, backups, generated runtime env files,
or release artifacts.
