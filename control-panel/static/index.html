Unlock the Control Panel

Paste the Control Panel token from your boat computer. It stays in this browser only.

Either form works: CONTROL_PANEL_TOKEN=abc123… or just abc123….

Don't have it? Run this on the boat computer:

sudo grep '^CONTROL_PANEL_TOKEN=' /opt/vesselstack/config/control-panel.env
How do I reach this panel?

By default the panel only answers on the boat computer itself, so nobody else on the dock network can open it. From your laptop, create a secure tunnel (SSH), then browse to the address below:

ssh -L 8780:127.0.0.1:8780 YOUR_USER@YOUR_PI.local

Leave that window open, then visit http://127.0.0.1:8780. If you changed the panel port in Settings, use that number instead of 8780.

Prefer to open it directly on your boat Wi-Fi? That is possible but sends the token unencrypted on that network. See the Control Panel guide before turning it on.

Maintenance

Occasional jobs. Each one says what it will do before it does it.

Backup

Back up nowSaves your settings and data to the backup folder. Services pause while the copy is made, so this can take a few minutes.
Restoring from a backup

Restoring replaces current data, so it is done from the boat computer on purpose, not from this page. Check the file first, then restore:

sudo vesselstackctl verify-backup <backup-file> sudo vesselstackctl restore <backup-file> --yes

Start & stop

Start allStarts every enabled service that is stopped.
Restart allStops and starts every service. Live data pauses for under a minute.
Stop allTurns off every service. The Control Panel stays available so you can start them again.

Setup & repair

Check setupChecks your saved settings and this Pi; changes nothing.
Reinstall & startRe-applies your saved settings and restarts every service. Live data pauses for about a minute.
Apply saved settingsPutting a change into effect is done with the Apply button on the Settings tab, after you save.

History storage

Set up history storageCreates the places where your boat's history is kept and the small background job that builds the one-minute averages. Safe to run again; nothing is lost.
